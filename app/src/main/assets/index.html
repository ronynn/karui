Box 4: About Karui

Karui

- A privacy friendly, lightweight, bloat-free open source todo list app with retro aesthetics made by ronynn.
- Use /tabName to add a new tab.
- You can just long press any tab to rename or delete it or add a new tab. Tap : to copy, edit or delete notes.
- You can restore notes from the recycle bin easily. If you accidentally delete a tab, restoring the individual notes will semingly go nowhere, just create a newtab with the same name and notes of that tab restored from the recycle bin will be there.
- Add a % symbol on any tabname and it automatically counts percentage of tasks completed.
- The Apollo mission operated on a computer with around 4KB of RAM! Karui's philosophy is to reach for the moon outgrowing limitations.
- Check out the github repository for source code and file issues for bugs if any are found. Also a small treasure hunt for you - the game has two easter eggs, the codes for which you can find in the source on github. Share your highscores on our reddit or discord, links available on Github readme.
