Box 4: Instructions
- Use /tabName to add a new tab. S is sort, E is enter, R on widget is refresh, M is for menu
- Long press from your launcher homescreen to add Karui widgets.
- You can just long press any tab to rename or delete it or add a new tab. Use Puff to delete marked notes. Tap : to copy, edit, pin or delete notes.
- You can restore notes from the recycle bin easily. If you accidentally delete a tab, restoring the individual notes will seemingly go nowhere, just create a newtab with the same name and notes of that tab restored from the recycle bin will be there.
- Add a % symbol on any tabname and it automatically counts percentage of tasks completed.
- Recurring notes (BETA): start a note with !Nx to repeat it. !1d daily · !3d every 3 days · !1w weekly · !2m every 2 months · !1y yearly. !m15 on the 15th of every month · !wsa every Saturday · !y05-01 every May 1st. Deleting one occurrence deletes the whole series (and restoring brings it back whole). Completing an occurrence automatically queues the next one.
- To Pin a note to status bar, add it as a journal/calendar entry for today.
- Ronynn made Karui with the intention of having the most aesthetic, fun and performant note taking app on android. Check out the github repository for source code and bugs/feature requests. Easter eggs: FLAPTHEBIRD, SLITHER, MOONMAN. Share your highscores on our reddit or telegram where we talk about foss apps, design and productivity.
